# 爆品、预测与补货规则

所有计算以 `sysSkuId` 为粒度。数量按件计算，不使用最小起订量、箱规或整箱取整。

## 1. 基础指标

```text
D1 = Q1
D3 = Q3 / 3
D7 = Q7 / 7
Dprev7 = Qprev7 / 7
增长率 = (D7 - Dprev7) / Dprev7
销售加速度 = (D1 - D7) / D7
```

`Dprev7=0、Q7>0` 标记新品起量，不输出无限增长。`D7=0` 不计算覆盖天数，也不生成销量驱动补货。

## 2. 最低门槛与信号

默认最低有效销量：`Q7 >= 14` 或 `D7 >= 2`。

强信号：

- 7日高增长：`Dprev7>0` 且 `D7 >= 1.5 × Dprev7`
- 头部销量：Q7 位于有效 SKU 前 10%，由上游传入 `is_top10=true`
- 绝对爆量：`Q1 >= 100`，阈值可按商家体量配置
- 新品起量：`Dprev7=0` 且 `Q3 >= 6`

普通信号：

- 短期加速：`D1 >= 1.5 × D7` 且 `Q1 >= 5`
- 持续加速：`D3 >= 1.2 × D7`

达到销量门槛后，命中任一强信号或同时命中两个普通信号，才是爆品候选。

等级：

- S：头部销量 + 7日高增长 + 持续加速
- A：7日高增长 + 短期加速或持续加速
- B：其他爆品候选
- 观察：未达到候选条件

## 3. 趋势状态

按以下顺序判断：

1. `Q3=0、Q7>0`：近期零销量待核对；在确认持续有货、在售且不是渠道缺数前，禁止自动预测。
2. 新品：`Dprev7=0、Q3>=6、Q1>0`。
3. 下降：`D1 < 0.5×D7` 且 `D3 < 0.8×D7`。
4. 上升：`D1 >= 1.2×D7` 或 `D3 >= 1.1×D7`。
5. 其他：平稳。

促销、直播、活动或异常大单商品必须标记 `event_driven=true`，降低结论置信度并要求人工确认，不能仅按峰值自动采购。

## 4. 预测日销

```text
平稳：D7
上升：0.5×D1 + 0.3×D3 + 0.2×D7
新品：D3
下降：min(D3, D7)
```

结果必须保留 D1、D3、D7 和趋势，不能只输出最终预测。

## 5. 库存与补货

```text
目标库存天数 = 到货周期L + 复盘周期R + 安全天数S
目标库存 = ceil(预测日销 × 目标库存天数)
库存位置 = 可配货库存 + 可用采购在途
补货触发库存 = 预测日销 × (L + S)
建议采购量 = max(0, 目标库存 - 库存位置)
现货可售天数 = 可配货库存 / 预测日销
```

只有确定能在目标日期前到货的在途才是“可用采购在途”。接口没有 ETA 时，可按静态公式展示试算，但必须提示风险，并拦截自动采购。

## 6. 优先级

- P0：爆品且 `现货可售天数 < L`，建议量大于 0。
- P1：爆品，现货可覆盖 L，但库存位置低于目标库存。
- P2：非爆品且库存位置低于补货触发库存。
- P3：爆品候选但样本不足、活动驱动或关键风险需要人工核对。
- 暂不补货：库存位置达到目标库存，或建议量为 0。
- 异常：负库存、映射缺失、数据不完整、近期零销量原因未知等硬门禁失败。

P0应同时输出断货应急动作：确认加急、跨仓调拨、控制推广、限购或替代供应商；采购并不一定能填补交期内断货窗口。

## 7. 取整与解释

目标库存和建议量按件向上取整。不得引入最小起订量或整箱规则。每条结果必须包含命中的爆品信号、趋势、库存覆盖、建议量公式和异常提示。
