# 输出模板

## 执行前版本确认

> 这次您需要哪种汇报版本？
>
> - 简约版：核心结论、关键数据、主要问题、下一步建议，适合快速查看。
> - 详细版：增加平台、店铺、商品、利润、售后、物流、数据口径和异常明细，适合深度复盘。

## 简约版模板

```markdown
# {周期}经营快报

**核心结论：** {一句话说明整体经营状态及最重要原因}

## 关键数据

- 销售额：{值}，{变化}
- 订单数：{值}，{变化}
- 净利润/毛利：{值或待校准}
- 售后：{值与变化}
- 物流：{异常或待处理数量}

## 主要问题

1. {对象 + 指标 + 原因}
2. {最多3项}

## 下一步建议

1. {明确动作}
2. {最多3项}

> 范围：{周期、平台、店铺}；未覆盖：{平台}；风险：{数据质量提示}
```

简约版禁止主动加入：API名、公式、十行以上表格、所有店铺排行、所有退款原因、长篇口径说明。

## 详细版模板

```markdown
# {周期}多平台多店铺经营分析

## 核心结论
{3—5条重要结论}

## 数据范围与口径
{周期、对比期、平台、店铺、销售/售后/物流时间口径}

## 整体经营概览
{销售、订单、利润、退款及变化}

## 平台分析
{平台规模、增长、利润、风险和机会}

## 店铺分析
{明星、潜力、风险、亏损、售后高发店铺}

## 商品与SKU
{高贡献、增长、亏损、高退款；数据不足则说明}

## 售后与物流
{平台、店铺、原因、预警、异常和待处理}

## P0—P3行动建议
{对象、指标、原因、动作}

## 数据异常与未覆盖范围
{测试数据、成本、映射、分页、平台覆盖}
```

## 数据质量降级模板

```markdown
# {周期}经营数据检查

**核心结论：** 分析链路已完成，但当前数据不满足正式经营决策要求。

## 发现的问题
- {最多3个最关键问题}

## 建议
- {先完成的数据治理动作}

> 本次仅用于链路或数据质量验证，不作为正式经营结论。
```
